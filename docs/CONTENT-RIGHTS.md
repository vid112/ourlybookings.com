# Content rights and demo data

The supplied reference websites were used only to understand public information architecture: categories, location discovery, ad-posting calls to action, adult notices and footer organization. Their names, logos, profile text, personal details, images and videos were not copied.

All bundled profile names and biographies are fictional demo data. The three bundled people images were generated specifically for this project and portray fictional adults in non-explicit editorial settings.

Before replacing demo content, the operator must retain private evidence that every person is an adult, consented to publication and authorized every media asset and profile detail. A credible dispute should trigger immediate unpublishing while evidence is reviewed.
